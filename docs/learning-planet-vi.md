# 学习星球 / Learning Planet VI

## 品牌定位

学习星球是 Helen 的长期多模态学习执行界面与学习记忆系统。视觉关键词是温暖、明亮、柔和、富有探索感的儿童学习宇宙。

它不是黑暗科幻宇宙，也不是幼儿园贴纸堆砌。正式课程内容来自上游课程设计师，网站负责呈现、交互、计时、记录、校验和导出反馈。

## 导航层级

1. 星系首页：只做学科选择，包括中文星球、字母星球、颜色星球、家长观察站。
2. 学科星球：展示本学科的阶段、登陆点和二级功能区。
3. 今日课程：一个明确的今日任务，按学习包顺序线性执行。

顶部固定导航只保留返回星系、当前星球、今日任务、家长观察站等少量入口。识字、生字本、字典、单词认读、积木英语和画廊归入二级页面。

## 色彩 Token

- 全局奶油天空：`#FFF8E8` / `#FFF4D8`
- 柔和浅绿环境：`#EEF7E8`
- 主文字：`#24313B`
- 次文字：`#62707A`
- 通用卡片：`rgba(255,255,255,.86)`
- 中文主色：`#F58A72`，浅面：`#FFE3D9`
- 字母主色：`#67AEEB`，浅面：`#DFF1FF`
- 颜色主色：`#A98BEA`，辅助桃色：`#F2A7B8`，浅面：`#F0E8FF`
- 家长观察站：`#76B7A5`，浅面：`#E1F3EC`

避免纯白满屏、纯黑宇宙背景、霓虹高饱和和大面积彩虹渐变。每个页面最多一个主学科色加一个小辅助色。

## 字体

正文优先使用 `PingFang SC` / system-ui，标题使用 `ui-rounded`、`SF Pro Rounded`、`Yuanti SC` 回退栈。儿童正文不低于 18px，按钮 16-18px，标题圆润但不牺牲汉字辨识。

## 插画语言

使用原创 2D 矢量或轻质感风格。星球是可辨认的大形状，每颗星球最多 3-4 个主题标志。星点、轨道和云雾必须低对比，不穿过正文。当前不使用随机 AI 人物图；星星姐姐形象未定稿前，用统一星光/小喇叭作为轻量引导。

## 组件

- 星球卡：大尺寸，圆角 24-32px，轻描边或柔和环形阴影，只包含名称、今日状态和一个主行动。
- 课程卡：圆角 16-24px，层级稳定，不为每张卡重新设计装饰。
- 触控目标：儿童主按钮不低于 48px；题目朗读小喇叭为 36-40px 的低调触控区。
- 进度：可用探索轨道或登陆点表达，但同时显示明确文字，如 `3/7步`。
- 状态：已完成、进行中、未开始、暂停必须图形加文字，不只靠颜色。

## 星球身份

- 中文星球：暖橙/珊瑚，故事、汉字、书页、语言生长。
- 字母星球：天空蓝/青绿，声音、交流、积木、旅行。
- 颜色星球：柔紫/桃粉，颜色、马克笔笔触、想象、作品。
- 家长观察站：薄荷绿加深灰蓝，安静、克制、偏控制台。

当前不显示数学、芭蕾、棋类或健身空星球。

## 动效

星球可非常缓慢漂浮，按钮按下轻微缩放。不使用持续旋转、大面积粒子、闪烁或彩带爆炸。支持 `prefers-reduced-motion`，关闭动态后功能和层级不受影响。

## 禁止事项

- 不照搬任何现成星球学习产品、页面或品牌资产。
- 不使用会干扰阅读的背景轨道、星点或装饰。
- 不用金币、排行榜、抽奖或惩罚式连续打卡制造压力。
- 不在正式课程页暗示 AI 可以临时改题、补题或生成课程。
- 不把答案、解析或检测目标通过朗读提前泄露。
